# Palm Crest Builders — Website

Static website for **Palm Crest Builders**, a licensed Class B general building contractor serving Los Angeles County and Southern California.

## Quick facts

- **Domain:** palmcrestbuildersinc.com
- **Stack:** Static HTML / CSS / JS — no framework; a small Python builder generates the service and city pages
- **Hosting:** Netlify (publishes this folder; `netlify.toml` at repo root). The `/admin` photo uploader is a password-gated page backed by the `admin-upload` Netlify Function (env vars `ADMIN_PASSWORD` + `GITHUB_TOKEN`), which commits photos to `images/gallery/uploads/` and appends to `data/gallery.json`.
- **Font:** Montserrat (Google Fonts)
- **License:** CA Lic. #[Pending] · Class B (replace the placeholder once the CSLB number is issued)
- **Forms:** Formspree endpoint `xeezrwvn`. Leads are tagged by a `source_domain` hidden field in `js/main.js` so you can filter Palm Crest Builders leads.

## Building

The 6 hub pages (index, about, contact, faqs, reviews, free-consultation) are **hand-authored** — edit the HTML directly.

The 10 service pages, 78 city pages, the areas index, `gallery.html`, and `sitemap.xml` are **generated**. After editing anything in `build/services/*.json` or `build/areas/*.json` (or adding/removing gallery images):

```bash
cd palmcrestbuilders
python build/build.py
```

This regenerates:
- `services/<slug>.html` for each service JSON
- `areas/<slug>/index.html` for each area JSON
- `areas/index.html` (city directory grouped by cluster)
- `gallery.html` (from every image in `images/gallery/`)
- `sitemap.xml`

No external dependencies — just Python 3.

## Adding a new city

1. Create `build/areas/<slug>.json`:
   ```json
   {
     "slug": "city-slug",
     "city": "City Name",
     "cluster": "San Fernando Valley",
     "short_blurb": "One-line description.",
     "neighborhoods": ["Neighborhood 1", "Neighborhood 2"],
     "local_note": "2–4 sentences of city-specific building/remodeling context.",
     "faqs": [
       { "q": "...", "a": "..." }
     ]
   }
   ```
2. Run `python build/build.py`.

Cluster options: `San Fernando Valley`, `Santa Clarita Valley & North County`, `San Gabriel Valley`, `Westside & Beaches`, `South Bay & Long Beach`, `Southeast LA County`. New clusters can be added in `build/build.py` in the `build_areas_index` function.

## Adding a new service

1. Create `build/services/<slug>.json` following the pattern of existing files (see `whole-home-remodeling.json` for the full schema: `slug`, `h1`, `tagline`, `metaDescription`, `intro_h2`, `intro`, `benefits[]`, `process[]`, `body_extra{}`, `faqs[]`).
2. Run `python build/build.py`.
3. Add the service card to `index.html` and the footer service lists.
